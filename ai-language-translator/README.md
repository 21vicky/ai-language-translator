
# 🌍 AI Language Translator

An AI-powered language translation application built using Python, PyTorch, Hugging Face Transformers, and Streamlit.

Translate English text into French using a pretrained MarianMT neural machine translation model.

## 🚀 Features

- English to French translation
- Pretrained Transformer-based translation model
- Simple and interactive Streamlit interface
- Copy translation and clear input
- Handles empty input
- Lightweight local execution

## 🛠️ Technologies Used

- Python
- PyTorch
- Hugging Face Transformers
- MarianMT
- SentencePiece
- Streamlit

## 🧠 AI Model

**Model:** `Helsinki-NLP/opus-mt-en-fr`

This pretrained model is based on the MarianMT architecture and is designed for English-to-French translation.

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/ai-language-translator.git
cd ai-language-translator
```

2. Create a virtual environment:

```bash
python -m venv venv
```

3. Activate it on Windows:

```powershell
venv\Scripts\activate
```

4. Install dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal.

The pretrained model will be downloaded automatically on the first run.
